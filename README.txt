КИНЖАЛ v4

WINDOWS:
1. Запустите start.bat двойным кликом.
2. Не закрывайте окно сервера, пока пользуетесь приложением.
3. Откроется http://localhost:8080

НОВОЕ В v4:
- программа тренировок на всю неделю;
- тренировка автоматически выбирается по дню недели;
- отметки каждого подхода сохраняются;
- таймер отдыха 30/60/90 секунд;
- воскресенье — восстановление;
- PWA-манифест и офлайн-кэш подготовлены для iPhone;
- данные v3 подхватываются автоматически при том же origin/порту.

IPHONE:
Для установки как отдельного приложения нужен HTTPS. Локальный localhost на Windows доступен только ноутбуку. Следующий этап — публикация папки kinzhal на HTTPS-хостинге, после чего открыть адрес в Safari на iPhone и выбрать «Поделиться» → «На экран Домой».

V5: пользовательские упражнения, дополнительная активность, цель калорий и ориентировочный перевод превышения калорий в минуты активности.
